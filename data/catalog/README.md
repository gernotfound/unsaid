# Catalog seed

The creative archive is split into small JSON chunks so it remains easy to review in Git.

- Public IDs use `UNS-xxxx`.
- `legacyId` preserves the previous prototype ID.
- `UNS-0001` is the approved FRONTE / RETRO product.
- Remaining records are concepts until their render and editorial review are approved.

These files are migration/seed data, not the production database.
